# 🥪 Deli Restaurant Ordering System 🥤

## 📌 Overview

The **Deli Restaurant Ordering System** is a Java console application that allows customers to create and customize sandwich orders for a deli restaurant. The system supports:

✅ Custom sandwich creation
✅ Signature sandwiches
✅ Topping customization
✅ Receipt generation
✅ Automatic receipt file storage

This project demonstrates important **Object-Oriented Programming (OOP)** concepts in Java such as:

* 🧱 Classes & Objects
* 🧬 Inheritance
* 🔒 Encapsulation
* 📂 File Handling
* 📋 Collections
* ⚠️ Exception Handling

# 🧾 Receipt Generation

When an order is completed:

✅ A receipt is generated
✅ The receipt is saved automatically
✅ Receipts are stored inside the `receipts` folder
✅ Each receipt is named using the current date and time

### 📄 Example Receipt Filename

```text id="7mh5vt"
20260528-121523.txt
```
